# DPO 采样多 GPU 并行化（v2）

将 DPO 采样从单 GPU 串行改为多 GPU 并行 + 可调 sub_batch_size，加速采样瓶颈。训练侧保持单卡不变。

---

## 1. 当前瓶颈

```
OnlineSampler.sample():
  for each reference NP (当前 1 个):
    for start in range(0, 16, 4):       ← 4 次串行 sub-batch on cuda:0
      generate(batch_size=4)             ← 主瓶颈：扩散推理 ~T 步
      group_id += 1                      ← 每个 sub-batch 一个 group_id
```

- `num_samples_per_molecule=16`, `inference_sub_batch_size=4` → 4 次串行 `generate()`
- 只用 `cuda:0`，其余 GPU 空闲
- `group_id` 语义：**每次 `generate()` 调用产生的 samples 共享一个 group_id**，downstream `evaluate_and_build_pairs()` 按 `group_id` 分组构建 preference pair

## 2. 方案

### 核心思路

将 sub-batches **按任务粒度分配到 N 个 GPU**，每个 GPU 持有一份**轻量**模型副本（只复制 `model`，不复制 `ref_model`），用 `ThreadPoolExecutor` 并行。**每个 sub-batch 保持独立 group_id**。

### 2.1 新增 `MultiGPUOnlineSampler`

**文件**: `Shepherd/src/shepherd/dpo_utils.py`

```python
from concurrent.futures import ThreadPoolExecutor
import threading

class MultiGPUOnlineSampler:
    def __init__(self, model_pl, params, devices):
        """
        devices: list[torch.device], e.g. [cuda:0, cuda:1, cuda:2]
        只复制 model_pl.model（推理用），不复制 ref_model。
        """
        self.params = params
        self.devices = devices
        self.sub_batch_size = params["sampling"]["inference_sub_batch_size"]
        self.num_samples = params["sampling"]["num_samples_per_molecule"]
        self.fixed_n_atoms = params["sampling"].get("fixed_n_atoms")

        # 每个 GPU 一份轻量 replica
        # 构造一个精简的 wrapper 只持有 model + params，不复制 ref_model
        self.replicas = []
        for dev in devices:
            replica = self._make_inference_replica(model_pl, dev)
            self.replicas.append(replica)

    @staticmethod
    def _make_inference_replica(model_pl, device):
        """只复制推理需要的 model + params，跳过 ref_model。"""
        model_copy = deepcopy(model_pl.model)
        model_copy.to(device)
        model_copy.device = device
        model_copy.eval()
        for p in model_copy.parameters():
            p.requires_grad_(False)

        # 构造一个轻量 wrapper，满足 generate() 对 model_pl 的接口要求
        # generate() 访问: model_pl.params, model_pl.model, model_pl.model.device
        wrapper = _InferenceWrapper(model_copy, model_pl.params)
        return wrapper

    def sync_weights(self, model_pl):
        """每轮采样前同步训练模型权重到所有副本。"""
        sd = model_pl.model.state_dict()
        for replica in self.replicas:
            replica.model.load_state_dict(sd)
            replica.model.eval()

    # _prepare_condition 直接复用 OnlineSampler._prepare_condition 的逻辑（可继承或 mixin）

    def sample(self, reference_molblocks_and_charges):
        generated_samples = []
        reference_mols = {}

        for mol_index, (mol_block, charges) in enumerate(reference_molblocks_and_charges):
            condition = self._prepare_condition(mol_block, charges, mol_index)
            reference_mols[mol_index] = condition["mol"]
            n_atoms = self.fixed_n_atoms or condition["mol"].GetNumAtoms()

            # 构建任务列表：每个任务 = 一次 generate() 调用 = 一个 group_id
            tasks = []
            remaining = self.num_samples
            while remaining > 0:
                bs = min(self.sub_batch_size, remaining)
                tasks.append(bs)
                remaining -= bs

            # Round-robin 分配到 GPU
            gpu_tasks = [[] for _ in self.devices]  # gpu_tasks[i] = [(task_idx, batch_size), ...]
            for task_idx, bs in enumerate(tasks):
                gpu_tasks[task_idx % len(self.devices)].append((task_idx, bs))

            # 并行执行，保持 task_idx → group_id 映射
            results_by_task = {}  # task_idx → list[sample]

            def worker(replica, assigned_tasks):
                """在指定 GPU 上串行执行分配给它的任务。"""
                local_results = {}
                for task_idx, bs in assigned_tasks:
                    with torch.no_grad():
                        samples = generate(
                            model_pl=replica,
                            batch_size=bs,
                            N_x1=int(n_atoms),
                            N_x4=max(1, condition["num_pharmacophores"]),
                            unconditional=False,
                            # ... 所有 inpaint 参数同 OnlineSampler ...
                            surface=condition["surface"],
                            electrostatics=condition["electrostatics"],
                            pharm_types=condition["pharm_types"],
                            pharm_pos=condition["pharm_pos"],
                            pharm_direction=condition["pharm_direction"],
                            verbose=False,
                        )
                    local_results[task_idx] = samples
                return local_results

            with ThreadPoolExecutor(max_workers=len(self.devices)) as executor:
                futures = []
                for gpu_idx, replica in enumerate(self.replicas):
                    if gpu_tasks[gpu_idx]:
                        futures.append(executor.submit(worker, replica, gpu_tasks[gpu_idx]))

                for future in futures:
                    results_by_task.update(future.result())

            # 按 task_idx 顺序组装，保证 group_id 语义与单卡一致
            global_group_id_base = mol_index * len(tasks)  # 或用累加器
            for task_idx in sorted(results_by_task.keys()):
                group_id = global_group_id_base + task_idx
                for sample in results_by_task[task_idx]:
                    sample["source_mol_index"] = mol_index
                    sample["group_id"] = group_id
                generated_samples.extend(results_by_task[task_idx])

        return generated_samples, reference_mols


class _InferenceWrapper:
    """轻量 wrapper，满足 generate() 对 model_pl 的接口要求。"""
    def __init__(self, model, params):
        self.model = model
        self.params = params

    def eval(self):
        self.model.eval()
        return self

    @property
    def training(self):
        return self.model.training
```

**group_id 语义保证**：每次 `generate()` 调用（一个 task）对应一个唯一 `group_id`，与单卡版行为完全一致。`results_by_task` 字典按 `task_idx` 排序组装，不会混组。

**显存优化**：`_make_inference_replica()` 只 deepcopy `model_pl.model`（推理网络），不复制 `ref_model`（DPO 参考模型）。每个副本的显存开销 = 1× 模型参数，而非 2×。

### 2.2 修改 `dpo_train.py`

**a) `main()` — 构建 sampler**

```python
# 显式指定采样 GPU ID
sampling_gpu_ids = params["training"].get("sampling_gpu_ids", list(range(torch.cuda.device_count())))
sampling_devices = [torch.device("cuda", i) for i in sampling_gpu_ids]

# 训练仍在 cuda:0
train_device = torch.device("cuda", 0)
model_pl.to(train_device)
model_pl.model.device = train_device

# 创建多 GPU sampler
sampler = MultiGPUOnlineSampler(model_pl, params, sampling_devices)
```

**b) `sample_preference_pairs()` — 签名统一**

```python
def sample_preference_pairs(sampler, params, reference_molblocks_and_charges):
    """采样 + 打分 + 构建偏好对。调用前需先 sampler.sync_weights()。"""
    scorer = ShepherdScorer(params)
    pair_builder = PreferencePairBuilder(params, scorer=scorer)
    generated_samples, reference_mols = sampler.sample(reference_molblocks_and_charges)
    return pair_builder.evaluate_and_build_pairs(generated_samples, reference_mols)
```

调用方统一：

```python
# main() 中初始采样
sampler.sync_weights(model_pl)
initial_pairs, initial_avg_score, initial_validity_stats = sample_preference_pairs(
    sampler, params, reference_molblocks_and_charges
)

# DPOSamplingCallback.on_train_epoch_end() 中
self.sampler.sync_weights(pl_module)
pairs, avg_score, validity_stats = sample_preference_pairs(
    self.sampler, self.params, self.references
)
```

**c) `DPOSamplingCallback` — 持有 sampler**

```python
class DPOSamplingCallback(pl.Callback):
```

### 2.3 参数配置

```python
# params_x1x3x4_dpo_finetune_nps.py
params["training"]["sampling_gpu_ids"] = [0, 1, 2]  # 显式指定采样用哪些卡
params["sampling"]["inference_sub_batch_size"] = 8   # 每个 sub-batch（视 VRAM 调）
params["sampling"]["num_samples_per_molecule"] = 24  # 总采样数
```

`sampling_gpu_ids` 支持：
- `[0, 1, 2]`：采样时 3 卡并行（含训练卡）
- `[1, 2]`：采样时只用非训练卡
- 不配置时默认使用所有可见卡

### 2.4 多 reference NP 扩展

当前设计已兼容：外层 `for mol_index` 循环不变，每个 reference 的 tasks 独立分配。后续可进一步将不同 reference 也并行化。

## 3. 实施步骤

1. **`dpo_utils.py`**: 新增 `MultiGPUOnlineSampler` + `_InferenceWrapper`，复用 `_prepare_condition`
2. **`dpo_train.py`**:

   - `DPOSamplingCallback.__init__` 增加 `sampler` 参数

4. 保留原 `OnlineSampler` 不删

## 4. 风险

| 风险 | 缓解 |
|------|------|
| GPU 显存不足 | `sub_batch_size` 可配，`sampling_gpu_ids` 可排除训练卡 |
| 副本显存 | 只复制 `model`（不含 `ref_model`），每副本 ~1× 模型参数 |
| `sync_weights` 延迟 | 每轮采样一次，~100ms 级 |
| `generate()` 线程安全 | 每线程独立 replica + device，无共享状态 |
| group_id 错乱 | `results_by_task[task_idx]` 按序组装，与单卡行为一致 |
| 训练卡显存竞争 | callback 在 epoch end 触发，训练不占计算图显存；或配置排除 cuda:0 |

## 5. 加速预期

3 GPU + batch_size=8, 24 samples:
- 3 tasks (24/8)，round-robin → 每 GPU 1 task → **1 轮并行**
- vs 当前 4 task 串行 → 理论 ~3-4× 加速

Scope：只加速采样阶段。训练侧（`pl.Trainer devices=1`）不变。
