# DPO 可视化迁移修正

修正 Shepherd 版 `_write_metrics()` 和 `visualize_dpo_metrics.py` 中的 4 个问题：pairs_detail 膨胀、status 缺失、缺失值用 0 而非 None、detail 缺 reference_idx/charge_method。

这份修正是对 `11.md` 的补全，但应按**完整可实施版**理解：除了下面 4 个修正点，还必须保留 `11.md` 里“从 SPD 迁移并适配 Shepherd schema”的前提，包括：

- `train_loss` 从 `m['train_loss']` 改为 `m['training_metrics']['train_loss']`
- `current_avg_score` 统一改为 Shepherd 的 `avg_score`
- 去掉对 `best_score` / `best_healthy_*` / `healthy_checkpoint_*` 的依赖
- 可视化脚本直接消费 Shepherd 写出的 JSON schema，不再假设 SPD 老字段存在

---

## 修改清单

### F1: pairs_detail 放 debug 开关后 (`dpo_train.py`)

**`DPOSamplingCallback.__init__`** 读取开关：
```python
self.save_pairs_detail = params["training"].get("save_pairs_detail", False)
```

**`_write_metrics`** 中 `pairs_detail` 改为条件写入：
- `self.save_pairs_detail == True` → 写入主 JSON（保持内联）
- `False`（默认）→ record 中不含 `pairs_detail` 字段

### F2: 显式存 status (`dpo_train.py`)

在 `_write_metrics` 的 record 中加 `"status"` 字段，逻辑：
```python
if sampling_error:
    status = "error"
elif num_pairs == 0:
    status = "empty"
else:
    status = "ok"
```

`visualize_dpo_metrics.py` 直接读 `m['status']`，去掉 `_derive_status()` 函数。

### F3: 缺失值用 None 代替 0.0 (`dpo_train.py` + `visualize_dpo_metrics.py`)

**`_write_metrics`**：
```python
def _safe_mean(vals):
    return sum(vals) / len(vals) if vals else None
```

`score_gap` 也改为：两侧均非 None 时才计算，否则 None。

**`visualize_dpo_metrics.py`**：绘图时将 None 视为缺失：
- `plot_winner_loser()` 和各手动绘图段：过滤 None 索引后绘制（与 training losses 同样的 `plot_series` 模式），非 None 点连线，None 处断线
- 摘要表 None 显示 "N/A"

### F4: pairs_detail 补 reference_idx + charge_method (`dpo_train.py`)

当 `save_pairs_detail=True` 时，每条 detail 增加：
```python
{
    "reference_idx": int(pair[2]),
    "winner": {..., "charge_method": pair[3].get("charge_method")},
    "loser": {..., "charge_method": pair[4].get("charge_method")},
}
```
