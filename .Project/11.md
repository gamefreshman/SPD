# DPO 训练中间数据可视化迁移

将 SPD 项目的 DPO 训练可视化方案（`_collect_and_save_metrics` + `visualize_dpo_metrics.py`）迁移到 Shepherd 项目。

---

## 1. 现状对比

### SPD（源）

- **`DPO1_0_triSim.py._collect_and_save_metrics()`**：每轮采样后聚合 winner/loser 的 6 项评分均值（surf, ESP, pharm, total, SA, logP），附带 score_gap、pairs_detail、iterative DPO 字段、buffer gate/protective stop 状态，写入 `dpo_round_metrics.json`
- **`visualize_dpo_metrics.py`**：读 JSON 生成 12 面板大图，含 EMA 平滑、平坦检测、pair count 背景柱、symlog 坐标、数据摘要表

### Shepherd（目标）

- **`dpo_train.py._write_metrics()`**：已写 JSON，但只有 `epoch, num_pairs, avg_score, validity_stats, training_metrics, ref_model_updated, buffer_gate, protective_stop`。**缺少 winner/loser 分项评分聚合和 pairs_detail**。
- **无可视化脚本**

### 数据可用性

Shepherd 的 pair 元组格式为 `(winner_mol, loser_mol, reference_idx, winner_scores, loser_scores)`，其中 `winner_scores`/`loser_scores` 已包含 `sims_surf_target, sims_esp_target, sims_pharm_target, total_score, sa_score, logp, charge_method`。数据完整，只需在 `_write_metrics` 中聚合。

## 2. 修改计划

### 2.1 增强 `_write_metrics()` — 聚合 winner/loser 分项评分

**文件**: `Shepherd/training/dpo_train.py`

修改 `DPOSamplingCallback._write_metrics()` 签名，增加 `pairs` 参数：

```python
def _write_metrics(self, ..., pairs=None):
    metric_keys = ['sims_surf_target', 'sims_esp_target', 'sims_pharm_target',
                    'total_score', 'sa_score', 'logp']

    winner_agg = {k: [] for k in metric_keys}
    loser_agg = {k: [] for k in metric_keys}

    for pair in (pairs or []):
        # pair = (winner_mol, loser_mol, ref_idx, winner_scores, loser_scores)
        w_scores, l_scores = pair[3], pair[4]
        for k in metric_keys:
            if k in w_scores and w_scores[k] is not None:
                winner_agg[k].append(float(w_scores[k]))
            if k in l_scores and l_scores[k] is not None:
                loser_agg[k].append(float(l_scores[k]))

    def safe_mean(vals):
        return sum(vals) / len(vals) if vals else 0.0

    record = {
        "round": len(self.metrics),   # 新增：轮次编号
        "epoch": epoch,
        "num_pairs": num_pairs,
        "avg_score": ...,
        "validity_stats": validity_stats,
        "training_metrics": training_metrics,
        # 新增字段 ↓
        "winner": {k: safe_mean(winner_agg[k]) for k in metric_keys},
        "loser": {k: safe_mean(loser_agg[k]) for k in metric_keys},
        "score_gap": safe_mean(winner_agg['total_score']) - safe_mean(loser_agg['total_score']),
        # 原有字段
        "ref_model_updated": ref_model_updated,
        "buffer_gate_passed": buffer_gate_passed,
        "buffer_gate_reason": buffer_gate_reason,
        "protective_stop_reason": protective_stop_reason,
        "sampling_error": sampling_error,
        # 新增：逐对详细数据（可选，方便调试）
        "pairs_detail": [
            {
                "winner": {k: float(pair[3].get(k, 0)) for k in metric_keys if k in pair[3]},
                "loser": {k: float(pair[4].get(k, 0)) for k in metric_keys if k in pair[4]},
            }
            for pair in (pairs or [])
        ],
    }
```

同时修改 `on_train_epoch_end()` 和初始采样处的 `_write_metrics` 调用，传入 `pairs`。

### 2.2 创建 `visualize_dpo_metrics.py`

**文件**: `Shepherd/training/visualize_dpo_metrics.py`

从 SPD 版本迁移，**适配 Shepherd JSON 格式**。主要差异点：

| SPD 字段 | Shepherd 字段 | 备注 |
|----------|--------------|------|
| `m['round']` | `m['round']` | 新增（见 2.1） |
| `m['train_loss']` | `m['training_metrics']['train_loss']` | 路径不同 |
| `m['status']` | 由 `sampling_error` 推导 | SPD 显式存 status |
| `m['current_avg_score']` | `m['avg_score']` | 字段名不同 |
| `m['best_score']` | 不存在 | Shepherd 未存，可从 `ref_model_updated` 推导或跳过 |
| `m['best_healthy_*']` | 不存在 | Shepherd 无 healthy checkpoint 机制 |

12 面板布局保持不变：
1. Surface Similarity (W/L)
2. ESP Similarity (W/L)
3. Pharmacophore Similarity (W/L)
4. SA Score (W/L)
5. LogP (W/L)
6. Total Score + gap fill
7. Score Gap + Pair Count (dual axis)
8. Training Losses (total, DPO, std)
9. Implicit Accuracy + DPO Weight
10. Model vs Ref Loss Diff (symlog)
11. Molecule Validity Rate
12. SA Score trend

保留功能：EMA 平滑、平坦检测+蒙版、pair count 背景柱、symlog、数据摘要表格。

去除 Shepherd 不存在的字段：`best_score`, `best_score_epoch`, `best_healthy_*`, `healthy_checkpoint_*`。

### 2.3 修改 `on_train_epoch_end()` 调用链

当前 `on_train_epoch_end()` 调用 `_write_metrics()` 时未传 `pairs`。修改为：

```python
self._write_metrics(
    epoch=trainer.current_epoch,
    num_pairs=len(pairs),
    avg_score=avg_score,
    validity_stats=validity_stats,
    training_metrics=training_metrics,
    ref_model_updated=ref_model_updated,
    buffer_gate_passed=buffer_gate_passed,
    buffer_gate_reason=buffer_gate_reason,
    protective_stop_reason=protective_stop_reason,
    sampling_error=sampling_error,
    pairs=pairs,  # 新增
)
```

初始采样的 `_write_metrics` 调用同理。
