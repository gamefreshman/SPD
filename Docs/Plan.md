### P5｜创新 1：离散-连续混合扩散引擎（0:40）
- **版式**：左半页公式对照表（连续 vs 离散），右半页 Joint Hetero Graph 结构示意图。
- **要点**：
  - **动机**：原 ShEPhERD 将原子类别 Embedding 后加高斯噪声 → "70% 碳 + 30% 氮"的中间态在化学上不存在。
  - **方法**：借鉴 DiGress 思路并扩展至多模态：
    - 离散通道（x1 原子/键、x4 药效团类型）：**马尔可夫转移矩阵 $Q_t$** + 经验边际分布先验，ELBO 从积分 $\int p\log\frac{p}{q}dx$ 改写为可微求和 $\sum p\log\frac{p}{q}$，以 `CrossEntropy` 直接回传。
    - 连续通道（3D 坐标、表面、场、药效团位置）：保留方差保持高斯扩散 + `MSE Loss`。
  - **耦合**：两通道经 6 层共享权重 Joint Hetero Graph Encoder（EquiformerV2）双向消息传递，实现"表面倒逼成键、药效团约束拓扑"。
- **左下角小字引用**：DiGress (ICLR 2023) + ShEPhERD (ICLR 2025)。
- **讲稿**："我们把离散扩散的数学形式严丝合缝地嵌入 ShEPhERD 的 4 模态架构，损失函数从 KL 积分自然过渡到分类交叉熵，梯度回传更稳定。"

### P6｜创新 2：DPO 多目标主动对齐（0:40）
- **版式**：左半页 DPO 数据流环（**采样 → Shepherd Scorer 打分 → Winner/Loser 配对 → Bradley-Terry 对偶损失**），右半页核心公式。
- **要点**：
  - **为什么是 DPO**：跳过 RLHF 里不稳定的 Reward Model，把不可微的多目标（QED、Surf/ESP/Pharm 相似度、SA、strain_energy）内化到 KL 约束内。
  - **Shared-Reference 语义**（本项目对 Diffusion-DPO 的关键扩展）：winner 与 loser 共用同一个 reference 的 `x3/x4` 条件，只在 `x1` 上差异化 → "同题比答案"。
  - **损失函数**（页面中央大号显示）：
    $$\mathcal{L}_{\text{DPO}} = -\log \sigma\Big(\beta\big[(\log\pi(w)-\log\pi_{\text{ref}}(w)) - (\log\pi(l)-\log\pi_{\text{ref}}(l))\big]\Big)$$
  - **工程亮点**：EMA reference 防坍塌、`real_data_ratio=0.5` 混合训练防灾难性遗忘、`dpo_ramp_up_epochs=10` 平滑引入。
- **右下引用**：Diffusion-DPO (Wallace et al., 2024)。
- **讲稿**："据我们检索，这是 DPO 首次系统迁移到 SE(3) 等变 3D 分子扩散模型——语言模型里 token 概率可以直接算，而扩散模型要用 ELBO 近似对数似然，这条数学链路是我们自己推出来的。"

### P7｜创新 3：时空协调化骨架跃迁（0:30）
- **版式**：三帧骨架跃迁过程示意（固定药效团 → 协调化修补 → xTB 弛豫后稳态），下方一条"时间轴噪声水平对齐"曲线。
- **要点**：
  - **问题**：固定区域 t=0 无噪、生成区域 t=T 高噪 → 交界处产生物理应力与断键。
  - **解法**：① **动态协调化掩码**，在每个时间步把固定区域的噪声水平拉齐到生成区域；② **时序停止控制**截断扩散轴，为连接处留出化学键微调窗口；③ **xTB 半经验量子弛豫**在线纠正几何应力（RMSD < 2.0 Å 阈值判定）。
  - **当前进度**：算法已闭环，完成 3 组小规模跃迁 case，大规模专利突围测试规划于下阶段。
- **讲稿**："针对骨架跃迁任务的时空状态冲突，我们提出了动态掩码——这是申报书第三个创新点，目前已完成算法开发与小样本验证。"
