# 直接偏好优化 (DPO) 微调架构

虽然通过“混合扩散结构”我们已经在生成有效分子、匹配构象方面取得了极为卓越的稳定性改善，但由于药物设计的应用场景极端长尾且目标极为苛刻（如高成药性、受限蛋白空腔匹配、消除构象膨胀冲突），基础的似然优化（Max Likelihood）只能保证结果“是一颗结构过关的分子”，而不能保证“它是现阶段我们需要的好分子”。

为此，本工程首次在此图生成模型框架之上嫁接了 **DPO (Direct Preference Optimization)** ，实现了从“无监督盲盒探索”向**“高分奖励牵引的主动演化”**的范式革新。

## 1. 为什么是 DPO？

- **克服 Diffusion 盲目性**：将难以量化和冲突的多目标，比如希望生成的药物能适应特殊的空间构象（$x2$）并同时满足成药性（SA/QED），转码内缩到损失函数的 KL 惩罚内。
- **避免多阶段 RL 崩塌**：对比传统的 RLHF，无需去训练一个不稳定的独立 Reward Model，而是通过构建偏好数据对 `(winner, loser)` 进行对偶损失博弈优化。

## 2. 偏好对（Preference Pair）机制 

### 2.1 在线动态采样
由于静态的数据集无法覆盖当前模型权重真实的生成弱点，我们专门利用 `OnlineSamplingCallback`，在每个 Epoch 中：
1. **抽发种子**：采样当前模型下，针对一组参考输入（比如同一个药效团 $x4$ 与结合口袋约束 $x2, x3$）。
2. **多线程分支采样**：使用当前生成器权重为同一参考结构生成 $K$（通常2~4）个不尽相同的随机候选。

### 2.2 Shepherd Score 评判标准
如何确认生成分子中谁是好分子 (winner) 谁是差分子 (loser)？我们构建了内部 `ShepherdScorer`，对多个属性打出评分总计：

| 评价角度 | 权重基准 | 代码逻辑来源 |
|---------|---------|-------------|
| **化学合理性（Validity, QED）** | ~40% | `scores['mqed'] * 2.0` (倾向具有类药性分子) |
| **点云契合性** | ~30% | `scores['sims_surf_upper_bound'] * 1.0` (在外部空间边界不越界) |
| **排斥与内部应变** | ~20% | `- scores['strain_energy'] * 0.5 - abs(scores['logp'] - 1.5) * 0.3` (剔除空间膨胀与热力学不稳定分子) |

提取分数极化差距超过特定阈值（确保非噪音差异）的一组分子，组合为：
`[Context_x2_x3, Output_Winner_x1_x4, Output_Loser_x1_x4]` 作为下一个阶段的主训练输入。

## 3. DPO 核心损失架构

### 3.1 冻结参考模型（Reference Model EMA）
DPO 最害怕模型放弃了先验知识，彻底崩塌为仅输出高分类似结构的过拟合状态。我们设计了**双向防重载屏障**：
- 在进入 DPO 循环时，复制一份基础扩散主干，并将 `requires_grad=False`作为 `ref_model`。
- 在每个 Epoch 尾声，实行极小补偿的 EMA（指数滑动平均）平滑更新策略，`ref_model_param = 0.99 * ref_model_param + 0.01 * model_param`，这保证了参考坐标系既不陈旧，又不盲目跟风。

### 3.2 对偶损失博弈公式 (Bradley-Terry)
在拿到偏好队列后，进入如下对抗博弈：
1. 让模型与其参考系在共享前置噪音与 $t$ 步时（Shared noise mapping ），分别预测 `winner` 与 `loser` 各自的预测误差（以及 logits概率）。
2. 让 `(模型对于胜者误差的减小 - 参考模型对于胜者误差的减小)` 不断扩大其针对于 `loser` 的相对差距：

$$ \mathcal{L}_{DPO} = -\log \sigma \left( \beta \times ( (\log \pi(w) - \log \pi_{ref}(w)) - (\log \pi(l) - \log \pi_{ref}(l)) ) \right) $$

这里的 $\beta$ 即 `beta_dpo` 参数，强制约束其相对扩散先验的远近距离。
> *注脚: 由于混合特性，我们会并行执行 MSE Loss 误差残差求导（针对连续分布坐标），与分类 CrossEntropy 求导（针对离散原子）。最后，与标准的生成加噪 Loss 会按照 $0.3 / 0.7$ 权重合成最终偏导梯度。*

通过 DPO 微调，我们极大缓解了模型后期 OOD （泛化外推）情况下面对大型、异形蛋白空腔，因空间拥挤造成的随机原子杂乱拼凑问题。
